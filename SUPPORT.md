# Support

<!-- wl:support.routes -->
Need help with ilinxa capture? Here's where to go:

- **Questions and usage help** — start a thread in
  [GitHub Discussions](https://github.com/ilinxa/ilinxa-capture/discussions).
- **Bugs and feature requests** — open a
  [GitHub Issue](https://github.com/ilinxa/ilinxa-capture/issues/new/choose).
- **Security vulnerabilities** — follow [SECURITY.md](SECURITY.md). Please don't
  use public issues for these.

Before opening an issue, check the [usage guide](docs/GUIDE.md) and the existing
issues. For bugs, include the version, your OS, and a minimal reproduction — it
gets you a useful answer faster.
